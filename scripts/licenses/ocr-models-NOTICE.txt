Japanese model modification by this application (compatibility: cjkcompat1):
The build removes ten legacy-engine configuration keys that are unavailable in
the LSTM-only Tesseract.js core, and the jpn_vert sublanguage request because
this application reads horizontal screenshots and does not bundle that model.
Only the config component and component offsets are rewritten. Every other
component, including learned weights, is verified byte-for-byte unchanged.
No warning is filtered or silenced at runtime.
