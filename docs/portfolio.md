## 作品概要

SPOTJOBSワーカーが補充・抜取の本数を記録し、週間報酬、手元の在庫、次のボーナス、目標までの追加本数を確認する非公式Webアプリです。個人制作の業務支援ツールとして、スマートフォンでの入力しやすさと、記録後の数字の分かりやすさを重視しました。

## 紹介文・100文字

SPOTJOBSワーカー向けの非公式Webアプリ。補充・抜取を手早く記録し、週間報酬、在庫、次のボーナスを見える化。表計算での管理をスマートフォン向けに作り直し、あと何本働くかを数字でも判断できます。

## 詳細紹介文・316文字

実際にSPOTJOBSの活動をスプレッドシートで管理する中で、移動中の入力や「あと何本補充すれば目標に届くか」の確認をもっと簡単にしたいと考え、Webアプリを制作しました。補充・抜取の大きな数字入力を中心に、早期補充の自動・手動判定、週次・地域別集計、棚卸差異、追加本数による報酬シミュレーションを実装。記録時の単価と週の条件を保存し、設定変更で過去の報酬が変わらないようにしています。データはIndexedDBに保存し、ログイン不要で利用可能。JSON復元とCSV取込には内容確認を設け、入力ミスや端末変更にも対応しました。Next.js・React・TypeScriptで構築し、初回読み込み後はオフラインでも使えるPWAです。

## 制作背景

実際のSPOTJOBS活動をスプレッドシートで管理していたことが出発点です。移動中に細かなセルを選択する負担や、次のボーナスを含めて報酬を見積もる手間を減らすため、入力と判断に必要な機能をWebアプリへまとめました。

参考資料として提供された報酬早見表の考え方も参照しています。資料の画像や記事本文を自作の成果として扱わず、アプリには独自に実装した画面と計算処理を掲載しています。

## 課題と実装

| 課題 | 実装した内容 |
| --- | --- |
| 移動中の入力が細かい | 大きな数字入力、数字キーボード、増減、+1・+2・+3・+5・+10ボタン |
| 報酬の暗算でボーナスを見落とす | 基本・早期・週間本数ボーナスを分け、到達段階を週全体に反映 |
| あとどれだけ働けばよいか分からない | 次の段階と目標までの追加本数、追加後の予想報酬を試算 |
| 在庫の繰越と早期対象が分かりにくい | 今日・昨日・一昨日の在庫表示、抜取日ごとの先入先出による推定 |
| 数えた在庫が記録と合わない | 棚卸を確認記録として保存し、明示的な確認後に在庫へ反映 |
| 単価変更で過去の数字が動く | 記録時の単価・早期条件・週開始日・ボーナス表を保存 |
| 端末内の記録を失いたくない | JSONバックアップ、復元前の内容確認、CSV出力・取込 |
| 電波の弱い場所でも入力したい | 初回オンライン読込後に使えるPWAとオフライン保存 |

## 主な機能

ホーム、補充入力、抜取入力、履歴、週次報酬、在庫・棚卸、報酬シミュレーター、設定の画面を用意しています。

履歴は日付・地域・作業種類で絞り込み、編集・削除・取り消しができます。設定は地域名・説明・単価、早期条件、週間ボーナス、週開始曜日、週間目標、ライト・ダーク・端末連動テーマに対応しています。個人データと分離したデモでも操作を試せます。

## 実装上の工夫

**計算と画面を分離しました。** 週の区切り、段階式ボーナス、在庫の先入先出、棚卸差異、追加本数の試算を純粋な計算処理にまとめ、境界値を単体テストで確認できる構成にしています。

**過去の報酬条件を保持します。** 補充ごとに適用した単価と条件を保存し、設定変更で過去の報酬が変わらないようにしました。記録がある週の区切りとボーナス表も維持します。

**不明な在庫を見える形で残します。** 抜取の記録が不足すると理論在庫を負値で示し、早期対象を推測で増やしません。棚卸は確認だけの記録と実際の在庫修正を区別します。

**保存の成功を確認してから画面へ反映します。** IndexedDBのトランザクション完了を待ち、別タブが先に更新していた場合は古い内容で上書きしません。旧データの移行に失敗した場合も移行元を保持します。

**データの持ち運びも検証します。** JSONではバージョン、日付、件数、単価、重複ID、記録時の条件を検証します。CSVは引用符や改行、日本語見出し、列割り当て、行別エラーに対応。アプリ出力CSVには元の記録を保持する列を付け、報酬条件や棚卸状態も復元できます。

## 紹介時の位置づけ

個人の実務上の不便を、入力しやすい画面と追跡できる計算へ置き換えた作品です。利用者数、削減時間、公式サービスとの提携など、確認していない成果は掲載しません。

本アプリは個人制作・非公式です。初期単価は変更可能な個人管理用設定であり、公式報酬を保証しません。記録はブラウザ内に保存し、ログイン・クラウド同期はありません。オフライン利用には初回のオンライン読込とキャッシュ保存が必要です。
