## Description

「ワークストック｜報酬と在庫」は、モバイルバッテリーの補充・取出を行う個人ワーカー向けの管理ツールです。

補充や取出をスマートフォンで素早く記録し、今週の見込み報酬、現在庫、早期補充、次の本数ボーナスまでまとめて確認できます。

主な機能

・補充／取出のかんたん入力
・本数を加算できるクイックボタン
・地域別単価と地域説明
・早期補充と週間本数ボーナスの自動計算
・次のボーナスまで「あと何本？」を表示
・週間目標まで必要な追加本数をシミュレーション
・現在庫、日別在庫、棚卸、棚卸差異の管理
・実際の保有数へ現在庫をすばやく修正し、差分履歴と取消を保持
・日次／週次履歴と地域別集計
・ジョブ履歴スクリーンショットの端末内読み取り
・今日または1週間の成績をXへ共有
・JSONバックアップ／復元、CSV入出力
・ライト／ダーク／システムテーマ
・主要機能のオフライン利用

記録の入力は手入力と、ジョブ履歴スクリーンショットの端末内読み取りです。記録はログインなしで端末内に保存されます。スクリーンショットの文字認識も端末内で行い、画像や認識結果を外部サーバーへ送信しません。端末変更や再インストールに備え、設定画面から定期的にJSONバックアップを保存してください。

表示する報酬は、入力内容とユーザーが設定した条件に基づく見込みです。確定金額や最新条件は、利用している作業アプリの公式サービスで確認してください。

本アプリは個人制作の管理ツールです。特定の公式サービスとの提携・関係はありません。公式アカウント、公式API、決済機能には接続しません。

## What to Test

1. 初回起動後、「サンプルを見る」でデモデータを表示できること。
2. 補充と取出を登録し、在庫と週間報酬へ即時反映されること。

6. ジョブ履歴のスクリーンショットを選び、候補を修正して保存できること。
7. JSON／CSVをFilesへ保存し、JSON復元とCSV取込のPreviewを確認できること。
8. 機内モードでアプリを再起動し、入力・Dashboard・履歴を利用できること。
9. 今日／1週間の成績を選び、Xの共有画面を外部ブラウザで開けること。
10. Light／Dark／System、文字拡大、VoiceOverで操作できること。

## App Review Notes

本アプリは、個人ワーカーが自分で入力した補充・取出記録から、報酬の目安と手元在庫を端末内で計算する独立した管理ツールです。

- ログイン、会員登録、課金はありません。
- 入力方法は手入力と、ジョブ履歴スクリーンショットの端末内読み取り（同梱のTesseract.js）だけです。PC連携やEdge拡張による自動取り込みは、本バージョンの配布ビルドに含みません。
- 公式API、公式アカウント、公式ロゴ、公式素材は使用しません。
- 特定の公式サービスが提供・承認する公式アプリではありません。提携・関係もありません。
- App本体、画面、計算ロジック、文字認識モデルはbinaryへ同梱しており、remote websiteを表示する構成ではありません。補充・取出・報酬・在庫・棚卸・履歴・OCRは通信なしで動作します。
- JSON／CSVの書き出しはiOSのファイル保存と共有シートへ統合し、X共有は既定の外部ブラウザで開きます。
- 入力記録は端末内のIndexedDBへ保存され、当方のサーバーへ送信されません。
- スクリーンショットOCRは同梱したTesseract.jsのモデルを使い、端末内で処理します。画像と認識文字は外部へ送信しません。
- 主要機能は通信なしで利用できます。X共有を開く場合だけ通信が必要です。
- 「現在庫を編集」は、実際の保有数へ在庫だけを補正します。補充・取出件数と報酬は変更せず、変更前後の差分を棚卸・差異履歴へ残し、保存直後はUndoできます。
- デモデータは、ホームの「デモデータで試す」、または設定の「サンプルを見る」から表示できます。個人情報を含みません。
- 広告SDK、アナリティクスSDK、クラッシュ収集SDK、クラウド同期は Version 1.0 に含みません。
